# Security policy

These examples run against live Orion tenants, so we take reports seriously.

## Reporting a vulnerability

Email **noah@bygravity.com** with:

- The file and example affected
- Steps to reproduce, or a proof of concept
- The impact you expect

Please don't open a public issue for a security problem. We'll confirm receipt and keep you updated until it's fixed.

## Scope

In scope: the scripts, workflows, and skills in this repository.

Vulnerabilities in the Orion product itself are also welcome at the same address. Product security details are in the [Orion documentation](https://docs.runorion.com).

## Supported versions

Only the latest commit on `main` is supported. Pull the latest version before reporting.
